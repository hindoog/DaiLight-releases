# DaiLight 다운로드

Windows와 macOS용 RAW 사진 편집기 DaiLight의 버전 정보와 실행 패키지를 배포하는 저장소입니다. 앱 소스 코드는 이 저장소에 포함하지 않습니다.

[최신 버전과 다운로드](https://github.com/hindoog/DaiLight-releases/releases/latest)

개발 초기 버전입니다. 각 릴리스의 지원 환경·제약과 패키지 안내를 읽고 사용하세요. Windows x64와 Apple Silicon Mac용 ZIP을 제공합니다. 현재 자동 설치·자동 교체 기능은 없으며, 0.1.1부터 앱의 **⋯ → 업데이트 확인…** 메뉴에서 새 버전과 변경 내용을 확인하고 내려받을 수 있습니다.

패키지에 포함된 외부 라이브러리의 라이선스와 고지는 `THIRD_PARTY`에 있으며, 필요한 대응 소스도 릴리스에 함께 제공합니다. 외부 라이브러리의 권리는 각 라이선스를 따릅니다.

업데이트 확인 시 GitHub의 공개 버전 정보만 조회합니다. 사진·카탈로그·편집값이나 계정 토큰은 전송하지 않습니다.
