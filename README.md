# DaiLight 다운로드

Windows와 macOS용 RAW 사진 편집기 DaiLight의 버전 정보와 실행 패키지를 배포하는 저장소입니다. 앱 소스 코드는 이 저장소에 포함하지 않습니다.

[최신 버전과 다운로드](https://github.com/hindoog/DaiLight-releases/releases/latest)

**1.0.0 정식판**은 macOS 13.4 이상 Apple Silicon용 ZIP으로 제공합니다. Windows용 1.0.0은 준비되는 대로 같은 릴리스에 추가합니다. DaisySoft 계정으로 로그인해 7일 무료 체험을 시작할 수 있고, 이후에는 구독으로 이용합니다([daisysoft.net/dailight](https://www.daisysoft.net/dailight)). 모든 사진 처리는 사용자의 컴퓨터에서 이루어지며 사진은 서버로 전송되지 않습니다.

Mac 앱은 아직 Apple 공증 전이라 처음 실행할 때 경고가 나올 수 있습니다. 앱을 Control-클릭해 **열기**를 고르거나 시스템 설정 → 개인정보 보호 및 보안에서 **그래도 열기**를 누르세요. 업데이트는 수동 설치 방식입니다.

0.1.x는 이전 개발판입니다. Windows 0.1.x 사용자는 Windows 1.0.0이 올라올 때까지 기존 버전을 그대로 사용할 수 있습니다.

패키지에 포함된 외부 라이브러리·AI 모델·Nikon SDK의 라이선스와 고지는 앱의 `THIRD_PARTY`에 있으며, 필요한 대응 소스도 함께 제공합니다. 외부 라이브러리의 권리는 각 라이선스를 따릅니다.

업데이트 확인 시 GitHub의 공개 버전 정보만 조회합니다. 사진·카탈로그·편집값은 전송하지 않습니다.
